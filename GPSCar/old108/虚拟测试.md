# 智能采摘小车虚拟测试记录

## 1. 目的与方法

本次使用虚拟串口、模拟 LD19 数据包、内存虚拟 SD 卡和虚拟 LCD，在 Windows 宿主机上用 MinGW GCC 直接编译并执行工程实际源码。没有重新实现一套替代算法。

测试对象：

- `Mid/Src/map_collent.c`：语义节点、四向连接、Dijkstra、局部栅格、MAP.BIN 存取和 CRC32。
- `Program/Source/lidar.c`：LD19 帧长、CRC8、角度插值、扇区距离和跨 0° 查询。
- `Program/Source/uart_host.c`：单字符、JSON Lines、语音意图、示教、急停/复位、地图上报及最近收发记录。
- `Mid/Src/menu.c`：启动后的首次绘制、主页信息、10 个功能页面、页面切换及 ESP 收发信息显示。

测试源码位于 `VirtualTest/`，硬件寄存器、FatFs、底盘、传感器和 LCD 驱动由桩接口替代。ESP 输入通过内存 FIFO 注入，LD19 输入逐字节送入实际解析函数，地图文件保存在 32 KB 内存缓冲区中。LCD 测试直接编译实际 `menu.c`，记录清屏和文本绘制调用，不依赖另一套界面实现。

## 2. 模拟数据

- 地图节点：`P0(0,0)`、`W1(100,0)`、`T2(100,100)`、`U3(0,100)`，单位为 cm；连接成四节点路线。
- LD19：构造标准 12 点、47 字节帧，起始角 359°、结束角 1°，距离 850 mm，强度 80；另构造一帧 CRC 损坏数据。
- ESP：输入手动前进、速度 0.45、添加 PARK 节点 `(1.5,2.5)`、语音 `start`、软急停、复位和地图请求；JSON 键值后保留空格。
- LCD/ESP 状态：注入速度、果数、电压、雷达/超声距离、GPS、ESP 在线状态、地图节点和 TF 卡文件信息；模拟 ESP 最近发送 `{"cmd":"status"}` 和接收 `{"cmd":"voice","text":"start"}`。
- 异常数据：不存在的目标节点、越界栅格坐标、被篡改的地图文件、错误雷达 CRC、急停状态下的前进命令。

## 3. 首轮发现的问题

| 模块 | 虚拟测试现象 | 原因 | 修复 |
|---|---|---|---|
| MAP.BIN | 保存成功但重新加载失败 | 写节点前未预留文件头，回写文件头覆盖首节点 | 打开文件后先写完整文件头，再写节点，最后回填 CRC |
| MiniMap 删除 | 删除后节点数仍为 4 | 原实现只清空槽位，没有压缩数组 | 按 ID 保存邻接关系，压缩节点数组并重建链接 |
| MiniMap ID | 删除、保存、加载后可能重复分配 ID | 加载后简单使用节点数作为下一 ID | 按文件中的最大 ID 计算下一 ID |
| ESP JSON | 带空格的 voice/estop/reset 不生效 | 部分命令使用固定无空格字符串匹配 | 统一先解析 `cmd` 字段，再按命令分发 |
| LD19 | 正常帧 CRC 错误，包计数不增加 | 47 字节帧被错误计算为 46 字节 | 帧长公式改为 `6 + 3*N + 5` |

## 4. MiniMap、LD19 与 ESP 测试

- MiniMap：18 项断言通过。
- LD19：8 项断言通过。
- ESP/USART2：9 项断言通过。

重点结果：

- 0 号节点到 2 号节点选择 `0 -> 1 -> 2`，路径长度 200 cm。
- 地图保存、清空、加载后节点数、邻接关系和路径长度保持一致。
- 地图 CRC 被篡改后拒绝加载，不继续使用损坏地图。
- 删除节点后计数正确，保存/加载再新增不会复用旧 ID。
- 359° 到 1° 数据可正确写入 359 和 0 扇区，跨 0° 最近距离为 850 mm。
- 坏 CRC 雷达帧不计入有效包，并累加错误计数。
- 语音 `start` 进入 PATROL；急停后前进指令不会驱动电机；复位后回到 IDLE。
- 示教命令中的米单位坐标正确转换为 cm 整数。
- ESP 完整行和单字符输入均更新最近 RX，所有 ESP 发送统一记录最近 TX，供界面调试查看。

## 5. LCD 启动与页面虚拟测试

针对“复位后显示 Smart Car，随后一直不显示内容”的反馈，启动流程改为开机画面结束后立即同步刷新主页，不再让清屏后的首次内容完全依赖 UI 任务调度；RTOS 任务创建失败时也会直接在 LCD 显示失败任务名。开机画面末尾不再额外清屏。

虚拟 LCD 测试覆盖：

- 启动后无需等待额外周期即可绘制主页，启动末尾无额外清屏。
- 主页显示 `Smart Picking Car`、READY/ESTOP、模式、运行状态、速度、果数、电压、雷达/超声距离、GPS、ESP 和地图节点信息。
- HOME、ESP、MOTR、SENS、MPU、GPS、IO、MAP、TF、DBG 共 10 页逐页绘制，每页均有有效内容。
- KEY2 可从主页切换到 ESP 页，ESP 页可见 RX/TX 计数、命令/错误计数及最近收发文本。
- TF 页显示卡状态、剩余空间、轨迹与地图文件信息，并保留 KEY4 同步轨迹入口。

**LCD：25 项断言通过。**

## 7. 测试边界

虚拟测试验证了软件逻辑、异常处理、启动后的界面调用和页面文本内容，但没有证明真实硬件时序。实际 ST7789 接线、供电、背光、SPI 时序、驱动初始化和 RTOS 任务调度仍可能影响显示，因此本次黑屏问题是否已在实物上消除必须烧录上板确认。DMA 环形缓冲 throughput、230400 波特率稳定性、PE0 电气去抖、100 ms 内断电、ESP32 无线连接和 K230/机械臂联调也仍需上板验收。
